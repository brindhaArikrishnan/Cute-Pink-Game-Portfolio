# 🌸 Cute Pink Game Portfolio 🎮

### ✨ A Cute, Interactive & Playable Developer Portfolio

Welcome to my **Cute Pink Game Portfolio**! 💗

This is a creative personal portfolio website that combines a cute pink aesthetic with an interactive mini-game. Visitors can explore my portfolio, discover my skills and projects, and enjoy a fun three-level gaming experience.

🔗 **Live Demo:** https://brindhaarikrishnan.github.io/Cute-Pink-Game-Portfolio/

---

## 🎀 About the Project

The Cute Pink Game Portfolio is a personal portfolio website designed with a soft pink and lavender theme. It includes an interactive game where players collect stars, avoid obstacles, and unlock new levels.

Instead of a traditional portfolio, this project offers a fun and engaging way to explore my developer profile.

## 🎮 Game Features

- 🌷 **Three Playable Levels**
  - Level 1 – Pink Garden
  - Level 2 – Magic Forest
  - Level 3 – Princess Castle
- ⭐ Collect stars to complete each level.
- 🚧 Avoid obstacles while playing.
- 🔓 Unlock new levels by completing previous levels.
- 🏆 Victory screen when a level is completed.
- 📱 Mobile-friendly touch controls.
- ⌨️ Keyboard controls for desktop players.
- 💾 Save game progress using Local Storage.
- 🔊 Sound effects for a more engaging experience.

## 💻 Portfolio Features

- 🎀 Cute pink and lavender design.
- 👩‍💻 Personal introduction section.
- 🛠️ Skills section.
- 🚀 Projects showcase.
- 📩 Contact section.
- 📄 Resume link.
- 📱 Responsive layout for different screen sizes.

## 🕹️ How to Play

1. Open the live demo.
2. Select an available level.
3. Use the keyboard or mobile controls to move your character.
4. Collect all the stars in the level.
5. Avoid obstacles and reach the exit.
6. Complete the level to unlock the next challenge.

## 🎮 Controls

| Action | Control |
|---|---|
| Move left | Left Arrow / A |
| Move right | Right Arrow / D |
| Jump | Spacebar / Up Arrow |
| Mobile gameplay | On-screen controls |

*Controls may vary slightly depending on the implementation.*

## 🚀 Run the Project Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/brindhaArikrishnan/Cute-Pink-Game-Portfolio.git
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure these files are present:

   ```text
   Cute-Pink-Game-Portfolio/
   ├── index.html
   ├── style.css
   ├── script.js
   └── README.md
   ```

4. Open `index.html` using the Live Server extension in VS Code, or open it directly in your browser.
